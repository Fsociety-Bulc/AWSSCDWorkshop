# Rehearsal checklist

## One week before

- [ ] Confirm the SMD is physically portrait and accepts a 768×896 source without cropping.
- [ ] Export HTML, PDF, and PPTX; test all three on the presentation laptop.
- [ ] Deploy the CloudFormation stack and complete a successful pipeline run.
- [ ] Replace any placeholder speaker/company details.
- [ ] Confirm the repository URL and regenerate the QR code.
- [ ] Record a clean 60–90 second fallback demo.

## One day before

- [ ] Restore `demo/app.js` to v1 values.
- [ ] Confirm the CloudFront site loads on a phone using mobile data.
- [ ] Confirm the GitHub Actions workflow may be manually dispatched.
- [ ] Save screenshots of v1, an in-progress workflow, a successful workflow, and v2.
- [ ] Clone or download the repository locally.
- [ ] Turn off operating-system and browser notifications.

## At the venue

- [ ] Test the actual 768×896 SMD input and safe margins.
- [ ] Set browser zoom to 150–175%.
- [ ] Check Wi-Fi and keep a phone hotspot ready.
- [ ] Open and order all demo tabs.
- [ ] Start with the HTML deck; keep PDF open as backup.
- [ ] Put the CloudFront URL and fallback media in bookmarks.
- [ ] Confirm the laptop is charging and sleep is disabled.

## Final verbal checks

- [ ] Define cloud without jargon.
- [ ] Explain DevOps as culture, practices, and automation.
- [ ] State the difference between permanent keys and OIDC temporary credentials.
- [ ] Mention rollback and cleanup.
- [ ] End with: small, automated, observable.
